# GitHub Push Policy

- Barcha yozilgan kodlar, o'zgartirishlar, tuzatishlar qilinganidan keyin yoki biror mantiqiy blok yakunlangach, ularni Githubga (omborga) darhol avtomatik tarzda `git push` orqali yuklang.
- Buning uchun foydalanuvchidan ruxsat so'rashingiz yoki ogohlantirishingiz shart emas. Har qanday o'zgarish darhol commit qilinib push qilinishi qat'iy qoidadir.
